# پیش‌بینی قیمت ماشین با یادگیری ماشین 🚗🤖

[🇬🇧 English](README.md)

این پروژه یک پروژه‌ی یادگیری ماشین از نوع **Regression** است که با استفاده از ویژگی‌های مختلف خودرو، قیمت آن را پیش‌بینی می‌کند.

## 📌 ویژگی‌های ورودی

مدل از ویژگی‌های زیر استفاده می‌کند:

- سال ساخت
- میزان کارکرد
- حجم موتور
- قدرت موتور
- تعداد درها
- برند
- نوع سوخت
- نوع گیربکس
- سابقه تصادف
- وضعیت خودرو

متغیر هدف:

- قیمت

## 🧠 تکنولوژی‌های استفاده‌شده

در این پروژه از موارد زیر استفاده شده است:

- `Python`
- `Pandas`
- `Scikit-learn`
- `LinearRegression`
- `train_test_split`
- `pd.get_dummies()`
- `R² Score`
