# Car Price Prediction 🚗🤖

[🇮🇷 فارسی](README.fa.md)

A Machine Learning regression project for predicting car prices from vehicle features.

## 📌 Features

The model uses the following vehicle features:

- Year
- Mileage
- Engine Size
- Horsepower
- Number of Doors
- Brand
- Fuel Type
- Transmission
- Accident History
- Condition

Target variable:

- Price

## 🧠 Technologies

This project uses:

- `Python`
- `Pandas`
- `Scikit-learn`
- `LinearRegression`
- `train_test_split`
- `pd.get_dummies()`
- `R² Score`

The dataset contains **1000 synthetic car records**.
